## Cómo está pensado el curso

- **Duración recomendada:** cinco sesiones de dos horas (10 h) más el trabajo final.
- **Formato:** sesiones demostrativas con ordenador y móvil. Cada concepto se acompaña de un ejemplo ejecutado en directo.
- **Requisito:** ninguna cuenta de pago. Todas las herramientas usadas tienen plan gratuito suficiente para el curso.
- **Principio de fondo:** la IA no sustituye el estudio; hace visible el proceso. Si no puedes explicar el resultado, no lo has aprendido.
